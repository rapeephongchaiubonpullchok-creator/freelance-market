# freelance-market

เครื่องเก็บข้อมูลตลาดงานฟรีแลนซ์จาก [Freelancer.com](https://www.freelancer.com) เก็บสดต่อเนื่องผ่าน GitHub Actions
เพื่อออกรายงานภาพรวมตลาดแยกตามสายงาน ระดับความเชี่ยวชาญ ราคา และความแออัด

**ไม่เก็บย้อนหลัง** ฟีดให้เห็นเฉพาะงานที่ยังเปิดอยู่ ประกาศที่ถูกจ้างแล้วหายออกทันทีและดึงกลับไม่ได้
สิ่งที่เก็บได้จึงเริ่มนับจากวันที่ตัวเก็บเริ่มเดินเท่านั้น

## ข้อมูลที่เก็บได้ไม่ได้อยู่ที่นี่

repo นี้มีแต่โค้ด ข้อมูลถูกเขียนลง repo ส่วนตัวอีกตัวหนึ่ง เพราะคำอธิบายงานเป็นข้อความที่ลูกค้าเขียนเอง
ไม่ควรถูกเผยแพร่ต่อ repo นี้เป็นสาธารณะด้วยเหตุผลเดียวคือนาที Actions ไม่จำกัด

## ไฟล์

| ไฟล์ | ทำอะไร |
|---|---|
| `freelance-market/collect.py` | ตัววนลูป — สามจังหวะ 2 นาที / 2 ชม. / 6 ชม. |
| `freelance-market/fmnet.py` | ชั้นเครือข่าย — คุมจังหวะยิง ถอยเมื่อถูกปฏิเสธ นับทุกรีเควสต์ |
| `freelance-market/store.py` | ที่เก็บ — หกสายรายวันแบบต่อท้าย และไฟล์สถานะหนึ่งไฟล์ |
| `freelance-market/rebuild_state.py` | กู้ไฟล์สถานะกลับจากสายข้อมูล เมื่อมันหาย |
| `freelance-market/probe.py` | ตรวจว่าสภาพแวดล้อมที่รันอยู่ยิงเว็บได้ไหม อ่านอย่างเดียว |
| `freelance-market/soak_report.py` | อ่านสาย runs แล้วตอบว่าถูกจำกัดอัตราหรือถูกหน่วงไหม |
| `grading/` | ขาตัดเกรด — คนละโปรแกรมกับตัวเก็บ รันที่เครื่องบ้าน ดู [`grading/README.md`](grading/README.md) |

## ความลับที่ workflow ต้องใช้

| ชื่อ | ใช้ทำอะไร | ถ้าไม่มี |
|---|---|---|
| `FM_DATA_SSH_KEY` | deploy key เขียนข้อมูลลง repo ส่วนตัว | ตัวเก็บเดินไม่ได้เลย |
| `FM_CHAIN_TOKEN` | PAT สิทธิ์ Actions: read and write บน repo นี้ ให้ job เรียกรอบถัดไปมาเข้าคิวเอง | ตัวเก็บยังเดิน แต่เหลือ cron เป็นยามตัวเดียว ซึ่งทำให้คิวว่างเปล่าค่ากลาง 127 นาที สูงสุด 288 ช่องว่างเมื่อตัวเก็บตายจึงยาวได้ถึง 6 ชม. |

`FM_CHAIN_TOKEN` หมดอายุได้ และ job จะแดงพร้อมเมลแจ้งเมื่อการเรียกรอบถัดไปล้มเหลว

## รันเอง

```sh
python3 freelance-market/probe.py                          # ยิงได้ไหม
python3 freelance-market/collect.py --data-dir .fmdata --once   # เดินครบทุกขารอบเดียว
```

ใช้ไลบรารีมาตรฐานของ Python ล้วน ไม่ต้องติดตั้งอะไร

## หมายเหตุเรื่องสัญญาผู้ใช้

สัญญาผู้ใช้ของ Freelancer.com ห้ามการเข้าถึงอัตโนมัติรวมถึง API และห้ามรวบรวมประกาศ
เจ้าของโปรเจกต์รับความเสี่ยงนี้แล้วโดยรู้ตัว ทุกรีเควสต์ยิงแบบไม่ล็อกอิน

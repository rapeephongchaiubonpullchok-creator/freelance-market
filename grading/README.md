# ขาตัดเกรด

โปรแกรมคนละตัวกับตัวเก็บ เดินทีหลัง และรันที่เครื่องบ้าน ไม่ใช่บน Actions เพราะตัวอ่านคือ
`claude-9arm` ที่ต้องผ่านเกตเวย์ที่บ้าน โค้ดอยู่ที่นี่ตามกฎบ้านหลังเดียว ถึงจะไม่ได้รันที่นี่

ตอนนี้มีแค่ **ด่านหนึ่ง** ซึ่งต้องผ่านก่อนลงแรงสร้างบันไดให้ครบทุกวิชาชีพ

## ด่านหนึ่ง — ผู้อ่านคนเดิมนิ่งไหม

ตัดเกรดชุดเดิม 50 งานห้ารอบ สลับตำแหน่งในชุดทุกรอบ แล้วนับว่าแต่ละงานลงขั้นเดิมกี่รอบ
เกณฑ์ของงานหนึ่งชิ้นคือ **≥4/5** ถ้าไม่ผ่าน ทางแก้คือลดขนาดชุดหรือซอยคำถามให้ปิดขึ้น
**ห้ามปรับบันได** เพราะด่านนี้ไม่ได้ถามว่าบันไดถูก — นั่นเป็นคำถามของด่านสองและด่านสาม

```sh
git clone git@github.com:<เจ้าของ>/freelance-market-data.git /tmp/fmdata   # กองข้อมูล
python3 grading/build_sample.py --data-dir /tmp/fmdata --out grading/out
python3 grading/run_gate1.py --out grading/out --dry-run | less            # ดูพรอมป์ก่อนยิง
python3 grading/run_gate1.py --out grading/out                             # ห้ารอบ ~26 นาทีต่อรอบเป็นค่าคาด
python3 grading/score_gate1.py --out grading/out
```

`--reader` ตั้งต้นเป็น `claude-9arm` เปลี่ยนได้ ส่วน `--reader-id` คือชื่อที่จะถูกบันทึกลงทุกแถว
พรอมป์ถูกป้อนทาง stdin ไม่ใช่ทาง argument เพราะทั้งชุดยาวราว 66,000 ตัวอักษร

## อะไรไม่อยู่ใน repo นี้

`grading/out/` ถูก ignore ไว้ทั้งก้อน เพราะมันมีคำอธิบายที่ลูกค้าเขียน ซึ่งเป็นเหตุผลเดียวกับ
ที่กองข้อมูลไปอยู่ repo ส่วนตัว ที่ส่งออกไปให้ตัวอ่านมีแค่คำอธิบายกับแท็ก ไม่มีหมายเลขงาน
ลิงก์ ชื่อผู้ว่าจ้าง หรืองบ อ้างกลับด้วยหมายเลขลำดับในชุดเท่านั้น

## ไฟล์

| ไฟล์ | ทำอะไร |
|---|---|
| `build_sample.py` | ตัดชุดทดสอบ 50 งานจากกองข้อมูล แล้วแช่แข็งไว้เป็นไฟล์เดียว |
| `run_gate1.py` | ยิงห้ารอบ สลับตำแหน่ง เก็บคำตอบดิบและแถวเกรดที่กำกับ rev ของไม้บรรทัดกับรุ่นของตัวอ่าน |
| `score_gate1.py` | นับความครบ ความนิ่ง ผลของตำแหน่งในชุด และสัดส่วนตกขอบ |
| `ladders/graphic-design.md` | ไม้บรรทัดฉบับร่างสองแกนของกราฟิกดีไซน์ ทุกขั้นยึดด้วยงานจริงยกเว้น K5 |
